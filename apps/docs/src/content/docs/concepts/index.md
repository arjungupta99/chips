Everything in Chips is built from these nouns. If a feature cannot be described with them, it is
probably the wrong feature. The same words appear in the schema, the app and these pages.

| Noun | What it is |
| --- | --- |
| [Participant](/concepts/participant/) | A person or a harness. |
| [Harness](/concepts/harness/) | What you run: Jacobian on the Mac mini, the agent you wrote beside it. The participant that is not a person. |
| [Space](/concepts/space/) | Where a harness works, with you in it. A worktree, a Jacobian Space, a room. |
| [Session](/concepts/session/) | A visit to a space. A terminal opens, works, closes; the space stays. |
| [Run](/concepts/run/) | A unit of harness work inside a space. |
| [Message](/concepts/message/) | Typed, not just text. Eleven kinds. |
| [Approval](/concepts/approval/) | A structured ask, with a preview and an expiry. |
| [Policy](/concepts/policy/) | Rules that decide which actions need a person. |
| [Audit event](/concepts/audit-event/) | An append-only record. Exportable, never editable; a deleted space leaves one line saying so. |
| [Lane](/concepts/lane/) | A run a lead routed to a specialist. |

Two pages that are not nouns but are worth reading next to them:
[Architecture](/concepts/architecture/), which is where each of these lives, and
[Supervision](/supervise/), which is how a person stays in charge of them.
