# Contributing to Chips

Chips doesn't take pull requests. If you'd like something changed, send a feedback prompt: what
you saw, what you'd change, and how to tell it's done.

Open one with
[New issue → Feedback prompt](https://github.com/arjungupta99/chips/issues/new?template=feedback-prompt.yml),
or from the app under You → Send feedback. [chipschat.ai/feedback](https://chipschat.ai/feedback)
says what makes a good one.

Found a security problem? Don't open an issue. [`SECURITY.md`](SECURITY.md) says where to send it.

You can still fork Chips and change it for yourself, as its licences allow
([`LICENSING.md`](LICENSING.md)).

## Getting set up

Node 22 LTS or newer and pnpm. Then:

```bash
pnpm install
pnpm check
```

How the people who make Chips work on it, and what CI checks, is in
[`docs/working-on-chips.md`](docs/working-on-chips.md).
