Scan a QR code from the Workspaces sheet

When you tap Primal at the top of Spaces, the sheet's Join with a link only takes a pasted link. The invite page on the other person's phone also shows a QR code, meant for somebody standing beside them. A phone that is already in a workspace has nowhere in Chips to scan it: the first screen has Scan a QR code, and this sheet doesn't.

Your words: "Should we also have QR code option button there?" Here are three ways to add it, smallest first. Tap Scan in A, B or C to see what it opens.

What Scan opens, the same for A, B and C

The sheet goes down, the camera comes up, and a code it reads opens the sheet a pasted link opens today.

What stays the same

  • The same sheet opens from the Workspace row on You, so Scan shows there too.
  • Paste works as it does now, with iOS's own button, so nothing asks to read the clipboard.
  • A newcomer's first screen keeps its own Scan a QR code. This only adds one for a phone that is already in a workspace.
