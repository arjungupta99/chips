Who a message is for

In a room with more than one agent, Chips works out who a message is for when it arrives, writes that on the message (addressed_to), and tells every agent the same thing. The agents it's for start a turn. The others hear it as context and stay quiet. Rooms with one agent, like J's room and every Space's room, don't change at all. Your pick: A, the capsule. This round draws where each message went with the routing mark rooms already use for lanes: faces joined by arrows, a circle for a person and a squircle for an agent.

A1 · A route over every message

Every message you send in a room with more than one agent wears its route. The @ and the route say the same thing twice, and a run of messages to one agent says it on every line.
Cost: the same as A2, minus one comparison.

A2 · A route where it changes recommended

The route marks where your address changed, which is exactly where rule 4's default moved. "and the PR checks?" gets none because it goes where the last one went, and the capsule already said so. On send, the capsule's arrow and face fly up with your words and become the route. Your own face joins it at the start. The capsule itself uses the arrow, so it reads as "where the next one goes".

Behind the room

The server does the addressing, so it holds for any agent, including one that knows nothing about the rule. It works it out once, when the message comes in, and records it in the log, so a replay gives the same answer. The route over a bubble is drawn from that record, never guessed again by the screen.

message.new: your turn

Only the agents in addressed_to get it. It's the event every agent already acts on, so an agent that knows nothing of the rule answers only what's addressed to it.

message.overheard: context

Every other agent in the room gets the same words as context, with no turn. An agent that doesn't know this event ignores it and loses nothing it has today. This one rule replaces the SDK-only rule for agent-to-agent messages from ADR 0077.

The guard

Chips counts agent-to-agent messages since a person last spoke in the room. After 4, the next ones still post, but address nobody, so no turn starts. The room shows one line, and the next thing a person says resets the count.
