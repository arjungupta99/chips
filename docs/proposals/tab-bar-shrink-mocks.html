The bar and the + shrink while you read

As you push a list up to read further, the tab bar and the + get a little smaller and the tab names go. Pull the list back down and they return. Today iOS does something else: it folds the bar down to one tab. All four phones scroll the same Spaces list at the same moment, so you can watch them side by side.

When it shrinks and when it comes back

  • It shrinks once the list has moved 24 pt toward later rows and you're past the first row.
  • It comes back when you pull the list 16 pt the other way, reach the top, or switch tab.
  • While small, a tab still switches on the first tap and the + still opens a new space.
  • The same on Spaces, Agents, Search and You. A room has no tab bar, so nothing changes there.
  • With Reduce Motion on, the names fade and the size changes without a spring.

Sprung or following the finger

Sprung is how iOS's own fold behaves: once the list has clearly moved, one spring of about 0.4 s takes the bar all the way. Follows the finger ties the size to the scroll over 52 pt, so it tracks the list exactly, then settles to whichever end is nearer when you let go. Safari's toolbar works this way. I'd pick Sprung: in a list you flick, a bar that tracks every point wobbles on small scrolls. Try both with the DRIVE buttons; they apply to B and C.
